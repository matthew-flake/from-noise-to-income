# Checklists

## 1. Licenses - before any paid project (Chapter 2)
- [ ] The program, every model file and the image itself all have a green light (three locks).
- [ ] Every model file (diffusion model, text encoder, VAE, LoRA, upscaler, helper model) is in my license register.
- [ ] I read the LICENSE file itself, not only the label - and noted the version and the date.
- [ ] Every file used in this project is category A. If unsure, it is B - not A.
- [ ] No famous characters, logos, brand names or real people without consent.
- [ ] No living artist's name in the prompt or the listing.
- [ ] I know the platform's AI rules and my disclosure sentence is ready.

## 2. Quality - before anything leaves my computer (Chapters 9 and 23)
- [ ] Checked at 100%: hands, faces, edges, stray letters, upscaling artifacts.
- [ ] The series is consistent: palette, light direction, scale, style.
- [ ] The image works as a small thumbnail.
- [ ] Transparency checked on black and on a color (no white halo).
- [ ] Print size calculated: inches = pixels / DPI. Test print made for new products.
- [ ] The QC sheet is filled in; rejects are really rejected.

## 3. Preparing for sale (Chapters 17 and 18)
- [ ] Files in the 3-5 most popular ratios, clear names (e.g. peony_16x20in.jpg).
- [ ] Workflow metadata removed from files for buyers (re-saved as JPG on purpose).
- [ ] sRGB for screens and most print-on-demand; print shop profile asked for when needed.
- [ ] One-page PDF with printing tips (for printables).
- [ ] Mockups: my own photos or licensed templates; the product is not misrepresented.
- [ ] Description: benefit first, what you get, how to use it, AI disclosure, what's not included.
- [ ] Platform fees calculated in the product calculator; break-even known.
- [ ] Go / change / drop criteria written down before the listing goes live.
